# Автотесты для Stellar Burgers (Sprint_5)

UI-автотесты для учебного сервиса Stellar Burgers: Python, pytest, Selenium WebDriver.

## Что проверяется

В проекте реализованы автотесты на следующую функциональность:

- **Регистрация:**
  - Успешная регистрация (имя не пустое, email в формате логин@домен, пароль от 6 символов).
  - Проверка ошибки при вводе некорректного пароля (меньше 6 символов).
- **Вход в аккаунт:**
  - Вход через кнопку «Войти в аккаунт» на главной.
  - Вход через кнопку «Личный кабинет» в шапке.
  - Вход по ссылке «Войти» из формы регистрации.
  - Вход по ссылке «Войти» из формы восстановления пароля.
- **Личный кабинет:**
  - Переход в личный кабинет.
  - Переход из личного кабинета обратно в конструктор (по кнопке и по логотипу).
  - Выход из аккаунта по кнопке «Выход».
- **Конструктор бургеров:**
  - Переключение между вкладками: «Булки», «Соусы», «Начинки».

## Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `locators.py` | Все локаторы (XPath) с подробными комментариями. |
| `helpers.py` | Вспомогательные функции: генераторы email/пароля, шаги регистрации и входа. |
| `conftest.py` | Фикстуры pytest: управление браузером, ожидания, подготовка пользователей. |
| `data.py` | Базовый URL проекта. |
| `tests/` | Папка с тестами, разбитыми по функциональности. |
